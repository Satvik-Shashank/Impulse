Financial Model Specification & Calculation Methodology [Click to expand/collapse]

Each strategy's net financial value is determined by the following unit cost parameters (modeled in INR):

  • True Positive (Automated Win): +₹2,250 saved per case (avoided human ops labor + successfully recovered transaction funds).
  • False Positive (Automated Loss): -₹1,000 lost per case (wasted card-network representment filing fee on an unwinnable dispute).
  • False Negative (Sent to Review): -₹350 operational labor cost per case escalated to human risk analysts.

Net Value Formula: Net Value = (TP × ₹2,250) − (FP × ₹1,000) − (FN × ₹350)

Security & Compliance

Defense-Only Guardrails & Documented Failures

Architectural constraints that guarantee security, zero PII exposure, and deterministic fallbacks.

Operational Guardrails

GuardrailImplementation Detail
No Dispute GenerationSystem only responds defensively to incoming chargeback webhooks; it never initiates or manufactures disputes.
No PII Exposure100% synthetic data generated via Faker (Indian BFSI context). No real customer data is stored or logged.
No Raw Card DataCard numbers are masked/tokenized upstream. System only accepts boolean match signals (avs_cvv_match).
Auditable Evidence RulesReason-code-to-evidence mapping is a deterministic rule table derived from published Visa/Mastercard representment specs.
Emergency Kill SwitchSet AUTO_RESPOND_CONFIDENCE = 1.0 to instantly route 100% of disputes to human review.

Documented Failure Modes & Handling

Failure ModeSystem BehaviorWhy This Is the Right Behavior
Weak / Absent Evidence HUMAN_REVIEW — never auto-submitted Auto-submit requires both confidence ≥ 70% and evidence strength ≥ 60% with ≥ 2 compelling pieces.
Ambiguous Mixed-Signal Platt calibration keeps confidence low → routes to review Platt scaling ensures confidence represents true probability, not an uncalibrated heuristic score.
Unknown Reason Code Falls back to generic.j2 with auto_respond_eligible = false System fails closed, not open, on unrecognized inputs.
High-Value + Strong Evidence Subject to standard threshold logic (no special-casing) Prevents arbitrary human overrides when stakes are highest — the same rules apply regardless of amount.
